# Canvas Design

Create manifesto-driven visual art as `.png` or `.pdf`. Not for UI, not for web pages — for static artifacts that are 90% visual design and 10% essential text.

Work in two phases: **Design Philosophy** → **Canvas Expression**.

## Phase 1 — Design Philosophy

Name an aesthetic movement (1-2 words: "Brutalist Joy", "Chromatic Silence"), then write a 4-6 paragraph manifesto covering:

- **Space and form** — how negative space and shape communicate
- **Color and material** — palette philosophy, intentionality
- **Scale and rhythm** — visual weight and beat
- **Composition and balance** — what governs placement
- **Visual hierarchy** — how the eye moves

**Critical guidelines:**
- Each aspect mentioned once — no redundancy
- Keep generic enough to work across contexts; leave room for interpretive choice
- Emphasize: information lives in design, not paragraphs

Output the philosophy as a `.md` file.

See `./references/canvas-design-philosophy-examples-and-manifesto-templates.md` for condensed example philosophies.

## Phase 2 — Canvas Expression

Before drawing, identify the **subtle conceptual thread** embedded in the original request — a niche reference woven into the composition so only those familiar with the subject feel it intuitively, while others experience a masterful abstract work.

Then create the artifact:

- Single-page `.pdf` or `.png` (multi-page only if requested)
- Repeating patterns, perfect shapes, dense accumulation of marks that reward sustained viewing
- Sparse, clinical typography — text as design element, never paragraphs
- Limited, intentional color palette
- Every element contained within canvas with proper margins — nothing overlaps, nothing falls off-edge

**Fonts**: No fonts are bundled; use installed or downloaded OFL fonts and name the font used.

**Quality bar**: Work must appear as though it took countless hours by someone at the top of their field. Meticulous spacing, color choices, typography, composition — everything screams expert craftsmanship.

## Final Pass — Refinement

After first output, take a mandatory refinement pass. Do NOT add new graphics. Instead: make existing elements more cohesive, crisper, more adherent to the philosophy. Ask: "How can I make what's already here more art?"

See `./references/canvas-creation-detail-instructions-and-quality-bar.md` for full canvas instructions.
